# 📝 AnswerBubble (Bubble Sheet)

A clean, minimalist, paperless answer sheet for taking practice exams and tryouts directly in your browser. 

Designed for anyone who already has digital exam papers/PDFs and just needs a fast, distraction-free bubble sheet to record answers, keep time, and review mistakes without printing or scribbling on physical paper.

---

## ✨ Features

- **⚡ Fast Keyboard Answering:** Fill choices (`A`–`F`) with single keystrokes, navigate with `↑` / `↓` / `Enter`, clear with `Backspace` or `0`.
- **⏱ Optional Exam Timer:** Set realistic test time limits with auto-cutoff locking when time runs out (+ quick unlock extension if needed).
- **📝 Per-Question Notes:** Jot down formulas, working steps, or mistake post-mortems right under each question.
- **🏷️ Subject & Tag Filtering:** Tag your sessions (`TPS`, `Physics`, `Math`, etc.) and filter your practice history easily.
- **🔄 Instant Retake:** Duplicate any test into a clean Attempt 2 without having to recreate question counts or configurations.
- **✏️ Flexible Session Editing:** Edit test title, subject, options count, or total questions at any time.
- **💾 100% Client-Side & Private:** All data persists in your browser's `localStorage`. Export and import JSON backups anytime.
- **🌗 Dark / Light Mode:** Matches your system preference automatically.
- **🚀 Zero Dependencies:** A single standalone HTML file with zero build step — deploy to Vercel, GitHub Pages, or open locally.

---

## ⌨️ Desktop Shortcuts

| Key | Action |
| --- | --- |
| `A` – `E` (or `F`) | Bubble option & advance to next question |
| `↑` / `↓` or `Enter` | Move focus between questions |
| `Backspace` / `0` | Clear selected answer |
| `N` | Toggle question notes |

---

## 🚀 Getting Started

Simply open `bubble-sheet.html` in any modern desktop or mobile browser, or host it on platforms like Vercel / GitHub Pages.
